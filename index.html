Abstract

Accurate automated segmentation of ischemic stroke lesions is essential for timely clinical decision-making and treatment planning. However, its practical implementation remains a significant challenge in low-resource clinical settings with limited computational infrastructure. This study proposes DSANet ISLES, an interpretable multi architecture ensemble framework for ischemic stroke lesion segmentation using multi modal MRI data. The proposed method integrates three complementary deep learning architectures, namely DerNet, SegResNet, and Attention U Net, to capture diverse spatial and contextual features. Multi modal information from FLAIR, DWI, and ADC sequences is combined into a unified 3D input representation to enhance lesion characterization. The models are trained independently and their predictions are fused using a weighted ensemble strategy, where optimal weights and threshold values are determined through grid search on the validation set. Additionally, Test Time Augmentation and morphological post processing are applied to improve prediction robustness and reduce false positives. Experiments are conducted on the publicly available ISLES 2022 dataset using a 70%, 15%, and 15% split for training, validation, and testing, respectively. Experimental results on the ISLES 2022 test set show that DSANet-ISLES achieves competitive segmentation performance with a Dice score of 0.8092 and a micro F1-score of 0.8814. The proposed framework demonstrates improved segmentation performance compared to individual models, highlighting the effectiveness of multi architecture fusion in low resource settings. It performs better where imaging quality and lesion presentation differ significantly. Future work will concentrate on combining temporal data and enhancing the model for real-time processing. These improvements will help neuroradiologists manage emergency strokes more effectively in low-resource settings.

Implementation Details, Weighted Formulation & Optimization Strategy

This section summarizes the finalized weighted equations and inference pipeline used in DSANet-ISLES for ischemic stroke lesion segmentation.

Weighted Ensemble Fusion

$$P_{ens} = w_D P_{DERNet} + w_A P_{AttUNet} + w_S P_{SegResNet}$$ $$w_D=0.8,\; w_A=0.2,\; w_S=0.0$$

Search grid: $w_D,w_A,w_S\in\{0,0.05,\dots,1.00\}$ with $w_D+w_A+w_S=1$. We impose $w_D\ge 0.40$ as a validation-driven prior because DERNet was the most stable single-model performer on the validation set; this avoids degenerate solutions that underweight the strongest backbone.

Decision Threshold & TTA Aggregation

$$\begin{aligned} P_{TTA}=\frac{1}{3}\Big(&P_{ens}(x) +Flip_x^{-1}(P_{ens}(Flip_x(x))) \\ &+Flip_y^{-1}(P_{ens}(Flip_y(x)))\Big) \end{aligned}$$ $$\hat{Y}=\mathbb{1}[P_{TTA} \geq \tau], \quad \tau=0.5$$

Threshold is selected from validation search. TTA probabilities are averaged first, then thresholding is applied.

Training Configuration

Data Split Public training set only, split 70% / 15% / 15%
Crop Size $64 \times 64 \times 64$
Optimizer AdamW
Learning Rate $1\times10^{-4}$ (Cosine Annealing)
Loss DiceFocalLoss / DiceCELoss
Epochs 100-150 (model-dependent)
Effective Batch 1-4 (model-dependent accumulation)

Algorithm 1: Validation Search and Final Inference

Input: Validation set V, test volume x, model probabilities P_D, P_A, P_S
Hyperparameters: weight step Delta_w = 0.05, threshold set T = {0.35,0.40,0.45,0.50}
Constraints: w_D + w_A + w_S = 1, w_D >= 0.40, w_i in [0,1]

1: bestScore <- -inf
2: for each feasible (w_D,w_A,w_S) on the simplex grid do
3:     P_ens <- w_D*P_D + w_A*P_A + w_S*P_S
4:     for each tau in T do
5:         Y_hat <- 1[P_ens >= tau]
6:         score <- ValidationMetric(Y_hat, V)   // Dice + Micro-F1 consistency
7:         if score > bestScore then
8:             (w_D*,w_A*,w_S*,tau*) <- (w_D,w_A,w_S,tau)
9:             bestScore <- score
10:        end if
11:    end for
12: end for

13: for a test volume x, compute probabilities for {x, Flip_x(x), Flip_y(x)}
14: map flipped outputs back to original orientation
15: P_TTA <- mean of the three probability maps
16: Y_hat <- 1[P_TTA >= tau*]    // threshold after averaging
17: remove connected components with size < 30 voxels

Final setting: $(w_D,w_A,w_S)=(0.8,0.2,0.0)$, $\tau=0.5$, and component filtering at 30 voxels.

Post-processing & Final Metrics

  • Random flips and $90^{\circ}$ rotations applied with 0.5 probability.
  • Morphological filtering removes connected components with size < 30 voxels.
  • The 30-voxel cutoff was selected on validation as a trade-off: it suppresses tiny isolated false positives while preserving clinically relevant lesions.
  • TTA is applied in probability space; averaging is performed before thresholding.
  • Final test performance: Dice $0.8092$, Micro-F1 $0.8814$.

Error Analysis

Detailed examination of segmentation errors using confusion trends and lesion-boundary failure patterns on ISLES 2022.

(a) Confusion Pattern Analysis

The confusion map highlights voxel-level agreement between predicted and reference masks. Strong diagonal concentration indicates stable lesion recognition, while off-diagonal activations reveal challenging edge and low-contrast regions.

(b) Boundary Error Analysis

Boundary-level inspection shows that most residual errors occur near weak-intensity lesion borders. These cases motivate post-processing and test-time augmentation to improve contour continuity and reduce spurious fragments.

Key Error Characteristics

Low-contrast boundaries: Primary source of under-segmentation in small lesions.

False positives: Mostly tiny isolated regions removed by connected-component filtering.

Mitigation: Weighted fusion + TTA improves robustness and mask consistency.

Future Directions
